Protegendo documentos acadêmicos com criptografia e assinatura digital.

Visão do problema

Risco de fraude

  • Documentos acadêmicos podem ser editados.
  • Alterações na nota ou no nome comprometem a autenticidade.
  • O verificador precisa confirmar origem e integridade.

Desafio técnico

  • O documento deve ficar protegido sem impedir a validação.
  • O sistema precisa garantir que qualquer alteração seja detectada.
  • A chave de origem não deve ser facilmente exposta.

Proposta

  • Usar AES-256-GCM para cifragem.
  • Usar SHA-256 para gerar o resumo do conteúdo.
  • Assinar digitalmente o hash para validar origem.

Fluxo de emissão

Este cenário simula a geração de um histórico acadêmico com proteção criptográfica e assinatura institucional.

Ir para validação

Validação de documento

O verificador apresenta o documento e o sistema calcula o hash para confirmar se a assinatura digital da instituição é válida.

Ver cenário adulterado

Cenário de adulteração

Uma cópia do documento é modificada. O hash difere e a assinatura digital deixa de validar.

Benefícios

  • Reduz risco de fraude acadêmica.
  • Permite verificação em canais externos.
  • Protege os dados pessoais dos estudantes.

Limitações

  • É uma POC educacional, não um sistema operacional completo.
  • Requer gestão real de chaves em ambiente seguro.
  • Precisa de políticas e auditoria para uso real.

Conclusão

  • O modelo combina criptografia e validação direta.
  • É adequado para demonstrar o problema e a solução.
  • Fica como base para evolução acadêmica e profissional.
